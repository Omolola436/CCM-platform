7. Consent Integrity

This is unique to CCMP.

Never overwrite consent.

Every consent should include:

Consent ID
User ID
Purpose
Legal Basis
Policy Version
Timestamp
Status

When a user withdraws consent:

Don't update the old record.

Create a new event while preserving history.

This gives you a complete audit trail.

Status: Critical
